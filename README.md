## 🇸🇦 العربية - العربية

### 📋 الوصف

**KAX - Cacio** هو تطبيق نقاط بيع (POS) شامل ومُصمم خصيصاً لإدارة عمليات البيع في المتاجر الصغيرة والمتوسطة. تم تطويره كتطبيق ويب واحد لسهولة الاستخدام والتشغيل.

### ✨ المميزات

| الميزة | الوصف |
|--------|--------|
| 📦 إدارة المنتجات | إضافة، تعديل، حذف المنتجات مع الصور والأسعار |
| 📊 مبيعات اليوم | عرض وتتبع جميع مبيعات اليوم مجمعة حسب المنتج |
| 🛒 سلة مشتريات | إدارة سلة المشتريات مع إمكانية إضافة/حذف المنتجات |
| 💳 أساليب الدفع | نقد، بطاقة، تحويل بنكي |
| 🧾 الفواتير النهائية | طباعة فاتورة مبوبة تتضمن جميع مبيعات اليوم |
| 🌍 متعدد اللغات | العربية، الإنجليزية، الكرمانجية، السورانية |
| 🎨 ثيمات | فاتح وداكن |
| ⌨️ اختصارات لوحة المفاتيح | ضغط مفتاح المنتج لإضافته للسلة |
| 💾 تخزين محلي | جميع البيانات تُحفظ في المتصفح |

### 🚀 كيفية الاستخدام

#### 1. فتح التطبيق
- افتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Edge, Safari)

#### 2. إضافة المنتجات
- اضغط على زر "إضافة منتج" في الشريط الجانبي الأيسر
- أدخل اسم المنتج والسعر
- (اختياري) اضغط على أيقونة الكاميرا لإضافة صورة

#### 3. البيع
- اضغط على منتج من القائمة لإضافته للسلة
- أو اضغط على مفتاح المنتج في لوحة المفاتيح (إذا تم تعيينه)
- كرر لإضافة منتجات أخرى
- اضغط على "إتمام البيع" لاستكمال الصفقة

#### 4. اختيار طريقة الدفع
- **نقد** - الدفع نقداً
- **بطاقة** - الدفع ببطاقة ائتمان
- **تحويل** - التحويل البنكي

#### 5. طباعة الفاتورة النهائية
- اضغط على "الفاتورة النهائية" في لوحة مبيعات اليوم
- يظهر نافذة تحتوي على:
  - ملخص اليوم
  - قائمة المنتجات المباعة مع الكميات والأسعار
  - الإجمالي الكلي
- اضغط على "طباعة" لطباعة الفاتورة

#### 6. الإعدادات
- اضغط على أيقونة الإعدادات ⚙️
- تغيير اللغة أو الثيم (السمة)

### ⌨️ اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---------|---------|
| `الاسم` | إضافة المنتج للسلة عند الضغط |
| `الإعدادات` ⚙️ | فتح نافذة الإعدادات |

## 🇬🇧 English - English

### 📋 Description

**KAX - Cacio** is a powerful, modern Point of Sale (POS) application designed specifically for managing sales operations in small to medium-sized stores. Built as a single-file web application for easy deployment and usage.

### ✨ Features

| Feature | Description |
|---------|-------------|
| 📦 Product Management | Add, edit, delete products with images and prices |
| 📊 Today's Sales | View and track all daily sales aggregated by product |
| 🛒 Shopping Cart | Manage cart items with add/remove functionality |
| 💳 Payment Methods | Cash, Card, Bank Transfer |
| 🧾 Final Receipts | Print organized receipts showing all daily sales |
| 🌍 Multi-language | Arabic, English, Kurdish (Kurmancî & Sorani) |
| 🎨 Themes | Light and Dark modes |
| ⌨️ Keyboard Shortcuts | Press product key to add to cart |
| 💾 Local Storage | All data saved in browser |

### 🚀 How to Use

#### 1. Opening the Application
- Open `index.html` file in any modern browser (Chrome, Firefox, Edge, Safari)

#### 2. Adding Products
- Click "Add Product" button on the left sidebar
- Enter product name and price
- (Optional) Click camera icon to add an image

#### 3. Making Sales
- Click on a product from the list to add it to cart
- Or press the product's assigned keyboard shortcut
- Repeat for additional products
- Click "Checkout" to complete the sale

#### 4. Selecting Payment Method
- **Cash** - Cash payment
- **Card** - Credit card payment
- **Transfer** - Bank transfer

#### 5. Printing Final Receipt
- Click "Final Receipt" button in Today's Sales panel
- Opens a window showing:
  - Daily summary
  - List of sold products with quantities and prices
  - Grand total
- Click "Print" to print the receipt

#### 6. Settings
- Click the Settings icon ⚙️
- Change language or theme

### ⌨️ Keyboard Shortcuts

| Key | Function |
|-----|----------|
| `Product Key` | Add product to cart when pressed |
| `Settings` ⚙️ | Open settings window |
